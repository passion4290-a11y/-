전기버스 멀미 저감 앰비언트 시스템

사이언(Cyan) 계열 시각 자극을 통해 전정기관과 시각 정보의 괴리를 최소화하는 실험 시스템

Version 1.0  ·  운영 매뉴얼
시스템 구조
[휴대폰] 가속도 센서 수집 │ WebSocket (wss://) ▼ [노트북] Python 서버 (포트 8765) │ 칼만 필터 → 색상/흐름 파라미터 계산 │ Cloudflare Tunnel (외부 HTTPS 주소 생성) ▼ [태블릿] 앰비언트 디스플레이 │ · 사이언 배경 호흡 (6.5초 주기) │ · 좌우 이동 → 색조(Hue) 변화 + 엣지 글로우 │ · 기울기 연동 수평선 (시각 기준선) │ · 중앙 고정점 (Focus Anchor) [컴퓨터] 모니터링 대시보드 → CSV 다운로드
왜 Cloudflare Tunnel이 필요한가?
iPhone은 보안 정책상 HTTPS 환경에서만 기기 센서(가속도계) 접근을 허용합니다. Cloudflare Tunnel이 로컬 서버에 자동으로 HTTPS 주소를 부여합니다.

사전 준비 (최초 1회)
1
Python 설치 확인
cmd 창을 열고 아래 명령어 입력. Python 3.x.x 가 뜨면 OK.
python --version
Python이 없으면 python.org에서 설치. 설치 시 "Add Python to PATH" 반드시 체크.
2
프로젝트 파일 다운로드
GitHub 저장소 → branch: claude/car-motion-ambient-system-Fum6y 선택
초록색 Code → Download ZIP 클릭 후 바탕화면에 압축 해제
압축 해제 후 폴더 안에 server / phone / tablet / monitor 폴더가 있어야 합니다.
3
cloudflared 다운로드
아래 파일을 다운받아 바탕화면에 놓기 (1회만)
https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
4
패키지 설치 (1회만)
윈도우 키 + R → cmd → 엔터 후 아래 입력. (폴더명은 실제 압축 해제된 이름으로)
rem 예시: 폴더 이름이 main 인 경우 cd %USERPROFILE%\Desktop\main\--claude-car-motion-ambient-system-Fum6y\server pip install -r requirements.txt
Successfully installed 가 뜨면 완료. 다음부터는 이 단계 생략.
매일 구동 순서
cmd 창을 2개 열어야 합니다. 두 창 모두 실험이 끝날 때까지 닫으면 안 됩니다.
1
cmd 창 1 — Python 서버 실행
윈도우 키 + R → cmd → 엔터
rem 폴더명을 실제 이름으로 변경 cd %USERPROFILE%\Desktop\폴더명\--claude-car-motion-ambient-system-Fum6y\server python -m uvicorn main:app --host 0.0.0.0 --port 8765
아래 문구가 뜨면 성공. 이 창을 닫지 마세요.
Uvicorn running on http://0.0.0.0:8765
2
cmd 창 2 — Cloudflare Tunnel 실행
새 cmd 창을 열고 입력
cd %USERPROFILE%\Desktop cloudflared-windows-amd64.exe tunnel --url http://localhost:8765
아래처럼 https 주소가 뜨면 성공. 이 주소를 메모하세요. 이 창도 닫지 마세요.
https://xxxx-xxxx-xxxx.trycloudflare.com
⚠️ 주소는 실행할 때마다 바뀝니다. 매번 새로 확인해야 합니다.
3
모니터링 PC — 대시보드 열기
노트북 Chrome / Edge에서 접속
http://localhost:8765/monitor
4
태블릿 — 앰비언트 화면 열기
브라우저 주소창에 입력 (xxxx 부분은 2단계에서 메모한 주소)
https://xxxx-xxxx-xxxx.trycloudflare.com/tablet
검은 화면이 뜨고 자동으로 연결됩니다. 별도 입력 불필요.
5
휴대폰 (iPhone) — 센서 연결
Safari 주소창에 입력
https://xxxx-xxxx-xxxx.trycloudflare.com/phone
1. 입력창에 주소 자동 입력 확인
2. "탭하여 시작" 버튼 누르기
3. "동작 및 방향 접근 허용" 팝업 → 허용
상태 표시줄에 "연결됨" 이 뜨고 센서 수치가 움직이면 성공.
6
연결 최종 확인
노트북 cmd 창 1 (Python 서버)에 아래처럼 뜨면 모두 정상 연결된 것입니다.
[+] tablet 연결됨. phones=0, tablets=1 [+] phone 연결됨. phones=1, tablets=1
모니터링 대시보드 우측 상단에도 서버 · 휴대폰 · 태블릿 인디케이터가 파랗게 켜집니다.
앰비언트 시각 효과 설명
차량 상태태블릿 화면 변화멀미 저감 원리
정지 / 등속 사이언(187°) 기본색, 6.5초 주기 호흡 효과 0.15Hz 맥동이 부교감신경 활성화 → 심박 안정
좌회전 색조가 민트(175°)로 이동, 우측 엣지 강조, 파티클 우→좌 흐름 시각 정보가 전정기관 신호와 일치 → 괴리 감소
우회전 색조가 청색(200°)으로 이동, 좌측 엣지 강조, 파티클 좌→우 흐름 동일
가속 밝기(Lightness) 감소 → 더 깊고 차분한 톤 시각적 안정감 제공, 뇌의 예측 오류 감소
감속 / 제동 밝기 증가 → 더 밝은 톤 감속 예고 시각화
기울기 수평선이 차량 기울기 반대로 미세 회전 인공 시각 기준선 → 공간 지각 안정
실험 전 체크리스트
  • 노트북, 태블릿, 휴대폰 모두 충분히 충전됨
  • 3기기 모두 동일한 Wi-Fi에 연결됨
  • cmd 창 1 — Python 서버 실행 확인 (Uvicorn running)
  • cmd 창 2 — Cloudflare Tunnel 주소 확인 및 메모
  • 태블릿: /tablet 접속 후 자동 연결 확인
  • 휴대폰: /phone 접속 후 센서 권한 허용 및 연결 확인
  • 모니터링 PC: /monitor 에서 모든 인디케이터 파란색 확인
  • 휴대폰을 흔들었을 때 태블릿 색상이 변하는지 확인
  • CSV 다운로드 버튼 동작 확인 (데이터 기록용)
문제 해결
증상원인해결
서버 cmd에서 "Could not import module main" server 폴더 밖에서 실행 cd ... \server 후 다시 실행
태블릿 / 휴대폰 접속 안 됨 Cloudflare Tunnel이 꺼짐 cmd 창 2 확인 후 없으면 cloudflared 재실행
Error 1033 Cloudflare가 서버를 못 찾음 Python 서버 먼저 켜고 cloudflared 재실행
휴대폰 센서값이 0.00 으로만 표시 iOS 센서 권한 미허용 Safari 새로고침 후 버튼 누를 때 팝업에서 "허용"
모니터에 "phones=0" 으로 표시 휴대폰 연결 안 됨 휴대폰 페이지 새로고침 후 재연결
Cloudflare 주소가 이전과 다름 cloudflared 재시작 시 주소 변경됨 새 주소를 태블릿·휴대폰에 다시 입력
