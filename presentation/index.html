05 — 피험자 수행 장면

1

탑승 전 Simulator Sickness Questionnaire 기초값 측정 — 오심, 어지러움, 시각 피로 항목

5분
2

기기 셋업 확인

태블릿 앰비언트 화면 정상 출력 확인 / 휴대폰 센서 연결 확인 / 엔진음 볼륨 조절

3분
3

주행 실험 (앰비언트 ON/OFF 교차)

동일 노선 2회 반복 — 1회차: 앰비언트 없음(대조군) / 2회차: 앰비언트 활성화(실험군). 순서 카운터밸런싱 적용

15분 × 2
4
